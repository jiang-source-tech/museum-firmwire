# 金潮杯博物馆固件更新记录

> 本文件只记录当前产品线的变更。旧项目更新日志已归档到 `docs/legacy/update-history.md`，不能作为当前需求、协议或验收依据。

## 0.2.0（2026-08-10）

### 完成旧业务隔离

- 1.46 目标板主界面切换为金潮杯博物馆页面，并接入 `museum_state` 显示路径。
- 删除电子宠物、Doorbell、Overview、课程/待办卡片和相关协议处理代码。
- 保留普通语音链路、可靠 TTS ACK、设置、电源管理、低功耗时钟和 OTA。
- 将旧设计、通知、宠物和可视化资料移入 `docs/legacy/`。
- 串口 REPL 提示符改为 `museum>`，调试测试和文档改用中性名称。

### 收紧服务端输入与迁移路径

- 固件不再处理服务端下发的任意 `notification` 或旧 `xiaoxin_event` 业务消息；设备自身的联网、低电量和 OTA 系统提示仍保留。
- OTA 返回的 WebSocket 地址必须使用 `/museum/v1/`；启动时会清除 NVS 中缓存的旧项目、旧主机或非博物馆 WebSocket 地址。
- 固件 OTA 默认入口改为正式 `/museum/ota/`。服务端保留的 `/xiaoxin/*` 只用于旧设备迁移，0.2.0 固件不再依赖这些旧路径。

### 当前验证边界

- 固件完整 Python 测试结果为 `227 passed`，博物馆主链路聚焦集合为 `16 passed`。
- 当前机器没有加载 ESP-IDF，因此未执行 0.2.0 的新构建；上述 Python 测试不能代替固件编译、烧录或真机验收。
- 生产服务器目录、容器、数据挂载、健康入口和 OTA 发布记录尚未确认，不执行生产部署。
