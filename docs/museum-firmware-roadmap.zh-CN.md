# 金潮杯博物馆固件路线图

> 更新日期：2026-08-10
> 适用范围：Waveshare ESP32-S3 Touch LCD 1.46 目标板
> 文档性质：当前固件能力和后续工作入口；历史宠物、课程、通知和 Overview 方案已移入 `docs/legacy/`，不得作为当前需求依据。

## 当前定位

固件是金潮杯博物馆的语音讲解终端，负责联网、语音链路、展品状态显示、临时系统提示、可靠 TTS 播放确认、设置、电源管理和 OTA。展品事实、访客会话和回答策略由服务端负责。

## 已完成能力

### 博物馆主界面

- 冷启动默认显示“金潮杯博物馆 / 正在连接讲解服务”。
- `museum_state` 消息经过版本、字段、长度和枚举校验后，转换为当前展品、讲解状态和提示文本并显示。
- 非法或过期状态被拒绝，不覆盖屏幕上的上一份有效状态。
- 聊天字幕、系统状态、低电量和 OTA 提示保留为独立的通用显示路径。

### 语音链路

- 保留普通 WebSocket/协议音频链路、唤醒词、ASR 文本显示和 TTS 播放。
- 可靠 TTS 使用 `ready`、`done`、`error` ACK，并在播放结束后恢复正确的聆听或待机状态。
- 串口 `museum_listen` 只用于验证语音链路入口，不等同于麦克风、ASR 或真机验收。

### 设置与设备状态

- 触摸设置页、亮度、Wi-Fi 重新配网、关于页、省电开关和低功耗时钟。
- 低电量、外部供电、主动低电关机、启动诊断和运行健康记录。
- OTA 保留 A/B 更新、哈希/尺寸/目标板校验和回滚门槛。

## 已移除的旧业务

以下能力不属于金潮杯博物馆当前产品，源码和构建入口已删除：

- 电子宠物 GIF、情绪、心情、行为、摇晃触发器和启动宠物动画。
- Doorbell MQTT、位置心跳、门铃凭据和反向唤醒链路。
- Overview、通知卡片分页、课程卡片、待办卡片和旧 `xiaoxin_event` 业务事件。
- 学生身份、课程/待办调度、主动陪伴、声纹绑定和旧控制台/小程序接口。

旧设计材料仍需保留时，只能放在 `docs/legacy/`，并在文档开头明确“历史资料，不是当前规格”。

## 兼容边界

- 当前正式路径为 WebSocket `/museum/v1/` 和 OTA `/museum/ota/`。
- 服务端不再提供 `/xiaoxin/*`、`/xiaozhi/*` 或旧 activation 兼容接口；固件保留的旧地址识别只用于清理 NVS 中的历史覆盖值。
- 0.2.0 固件只接受 OTA 返回的 `/museum/v1/` WebSocket 地址，并会清除 NVS 中缓存的旧主机、`/xiaozhi/v1/`、`/xiaoxin/v1/` 或其他非博物馆地址。
- 固件会拒绝旧 `/xiaozhi/ota/` 覆盖地址；新构建必须显式配置真实 `/museum/ota/` 入口。
- 1.46 分区表等底层产物可能仍带 `xiaoxin` 文件名；这是硬件兼容标识，不是产品身份。
- 电源、电池、设置、低功耗和运行健康模块仍有 `xiaoxin_*` 技术命名，后续可单独做低风险重命名，但不得与协议或行为清理混合。

## 后续工作

1. 在已加载 ESP-IDF 5.5 环境中完成目标板构建，并保存可复核的构建日志和产物 SHA-256。
2. 运行固件 Python 冒烟测试，确认 `museum_state`、可靠 TTS、低电量和 OTA 合同没有回归。
3. 在确认服务器目录、容器、数据挂载和健康入口后，再规划部署；当前不得沿用旧部署命令。
4. 明确真实设备、固件提交、服务端提交和测试路径后，执行一次可记录的真机联调。

## 当前验收口径

- Python 测试只能证明源码级合同；不能代替屏幕、麦克风、ASR、音频效果或 OTA 真机验收。
- 服务启动成功不能证明旧线上提醒已经停止；生产数据、日志和运行版本必须单独取证。
- 任何未被馆方审核资料支持的展品事实，都必须由服务端回答层明确拒绝或转为可验证的追问。
